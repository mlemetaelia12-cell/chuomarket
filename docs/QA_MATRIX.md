## Safe local checks on Windows PowerShell

After cloning the final ZIP/project and installing dependencies on a machine with npm access:

```powershell
npm ci
npx tsc --noEmit
npm run lint
npm run build
```

Use a separate development database/Neon branch, a non-production R2 setup, and Pesapal sandbox. Do not execute migration commands until the current database history has been reconciled and the owner approves a written plan.
